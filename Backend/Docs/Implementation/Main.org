* Database Setup

** SQLite and Foreign Key Constraints

By default, SQLite does not check for foreign key constraints [fn:1] [fn:2].
Since ~persistent-sqlite-2.6.2~, the ~SqliteConnectionInfo~ type represents the configuration setting for a SQLite connection. The ~mkSqliteConnectionInfo~ function generates one such configuration with foreign key constraints turned on by default [fn:3].
